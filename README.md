# CITEK_test_app

Данное приложение выполнено в рамках тестового задания для компании СИТЕК.

Возможности:
1. Позволяет отслеживать изменения в адресах, внесенные в Федеральную информационную адресную систему (ФИАС). Представляет изменения адресов как отчёт в виде документа PDF.
2. Позволяет отслеживать процесс работы приложения благодаря встроенному окну с логом и шкале загрузки.
